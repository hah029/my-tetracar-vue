# Ежедневные награды и боевой пропуск

Неделя — 7 дней (`DAILY_GIFT_WEEK_LENGTH`). Полный цикл определяется количеством дней в `DAILY_GIFT_REWARDS` (сейчас 28). Нумерация наград должна идти подряд с 1. После последнего дня начинается новый цикл.

`DAILY_GIFT_RECOVERY` в `index.ts` управляет восстановлением:

- `enabled`: включение платного восстановления;
- `minMissedDays`, `maxMissedDays`: включительный диапазон пропущенных дней (сейчас 1–3);
- `energonCost`: цена одного восстановления (сейчас 5 энергонов).

Даты считаются в UTC. Если подарок получен 1-го, а игрок вернулся 3-го, пропущен один день — 2-е число.

При пропуске бесплатный путь начинает календарь с дня 1. Боевой пропуск возвращает к началу недели последней полученной награды: дни 8–14 → день 8, 15–21 → день 15, 22–28 → день 22. Первая неделя сбрасывается к дню 1 бесплатно; покупать восстановление для неё не предлагается. Пропущенные дни не продвигают календарь вперёд.

Восстановление само не выдаёт награды и не увеличивает число получений. Награда первого дня восстановленной недели доступна сразу по кнопке «Забрать»; остальные дни этой недели проходятся заново. Если после восстановления не забрать подарок в тот же UTC-день, этот день считается пропущенным.

Перед списанием сохраняется незавершённая операция. После ошибки можно завершить её кнопкой или при следующей загрузке. Уже выполненное списание определяется по сохранённому балансу и повторно не выполняется. Если баланс изменился сторонней операцией и не совпадает ни с исходным, ни с итоговым, восстановление останавливается с ошибкой, чтобы не перезаписать чужое изменение. Платформа не предоставляет атомарной транзакции между данными календаря и балансом валюты.

Проверки: `node --test tests/dailyGift.test.mjs`.
