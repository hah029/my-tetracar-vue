# Пресеты колеса фортуны

Каждый набор хранится отдельным файлом в `presets/`. `standard` сохраняет исходные призы и вероятности; `supplies` содержит патроны и броню. Существующие источники круток выдают `standard`.

Чтобы добавить набор:

1. Создайте файл с объектом `FortuneWheelPreset`: стабильный `id`, `nameKey` и непустой массив `sectors`. Идентификаторы секторов должны быть уникальны внутри набора, веса — конечными положительными числами.
2. Импортируйте его в `index.ts` и добавьте в `FORTUNE_WHEEL_PRESETS`. Ключ реестра должен совпадать с `id`.
3. Добавьте название по `nameKey` в русскую и английскую локализации.
4. Укажите набор в награде: `{ type: "fortune_spin", effect: { presetId: "supplies", amount: 1 } }`.

Интерфейс автоматически показывает зарегистрированные наборы и их отдельные балансы. Размер секторов одинаковый; вероятность выигрыша определяется относительным `weight`.

Крутка списывается только у выбранного набора. Старое числовое сохранение `fortuneSpins` при загрузке переносится в `standard`; новые сохранения содержат JSON-объект с балансами по идентификаторам. Не переименовывайте выданные игрокам наборы без миграции сохранений.

В режиме разработки сохранена возможность бесплатного запуска при нулевом балансе выбранного набора. В production запуск требует крутку именно этого набора.

Проверка логики: `node --test tests/fortuneWheel.test.mjs` из корня проекта.
